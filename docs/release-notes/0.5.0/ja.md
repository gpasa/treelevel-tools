TreeLevel が含むことのできない GPL ツールを、あなたのマシンで — そこから外に出るものは何もありません。TreeLevel はサンドボックス化されていてプログラムを一切起動しません。このパッケージが、それらの実行を許されている側です。

### 0.5.0 の新機能

- **Pythia 8 が粒子を相互作用領域に配置します**。TreeLevel 1.4 が求めたとき（オプション「相互作用領域での位置」）に行います：各ハドロンがフェムトメートル単位でどこで生まれたか、パートンのカラーフローと状態、そして事象全体で一つのビーム衝突領域のずれ。TreeLevel はこれをフェムトメートルの尺度で、断面と 3D で表示します。
- TreeLevel 1.3 はこれを一切求めず、0.4.0 と同じ事象を受け取ります。生成器もバージョンも同じです。
- Apple Silicon の Mac と Intel の iMac で試しました：同梱の各生成器が実際の作業を実行します。

### インストール

- **Apple Silicon と Intel** の Mac 用、macOS 13 以降。
- `TreeLevel Tools.app` を `/Applications` にドラッグし、一度起動します。
- 四つの生成器が**すでに入っており**、ほかに何もインストールする必要はありません：
  - **Pythia 8** と **Herwig 7** は、二つのレプトン間の TreeLevel の事象に肉付けします：シャワー、ハドロン化、崩壊。**Pythia 8** は「加速器」ソースも動かします：二つのビーム、一つのエネルギー、そして衝突が生み出すすべて。
  - **Sherpa 3** と **CalcHEP 3** は、ダイアグラムが表す過程を自ら計算します。
- すると TreeLevel は「生成」ワークスペースでそれらを提示します。

すべての生成器のカードは、Docker イメージ内と同じ C++ エンジンで書き出されます：同じ作業は Mac でも Linux でも同じカードになります。

**WHIZARD 3** は含まれていません：各過程を gfortran でコンパイルしますが、gfortran は macOS にも Xcode にも付属しません。入手方法は二つあり、TreeLevel Tools のウィンドウでチェックします：

- **Docker イメージ** `ghcr.io/gpasa/treelevel-tools:latest`。五つのツールを備えています。チェックすると**すべての**作業をこれが実行し、ここに同梱の生成器は使われません；
- あなた**自身のインストール**（MacPorts、Homebrew）、お持ちであれば。

どちらも既定では使われません：初期状態ではここに同梱の生成器だけが提示されるので、同じ書類は二台のマシンで同じ結果になります。

Apple による署名と公証済み。チェックサムは `SHA256SUMS.txt` にあります。
