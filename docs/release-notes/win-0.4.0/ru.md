Ядро, которое запускает генераторы Монте-Карло для TreeLevel 1.3 в Windows. Устанавливается распаковкой архива в `%LOCALAPPDATA%\Programs` — ни установщика, ни записей в реестре. **Чтобы обновить** предыдущую версию: закройте TreeLevel и распакуйте архив в то же место, заменив файлы.

Выберите архив для своей машины: `arm64` для ПК Copilot+ или планшета на ARM, `x64` во всех остальных случаях. В случае сомнений x64 работает и на ARM, под эмуляцией.

**Что содержит архив**: `treelevel-tools.exe`, который запускает TreeLevel; `treelevel-engine.exe` — ядро, которое пишет карточку каждого генератора и ведёт его; модуль Pythia 8, скомпилированный для этой архитектуры; `CREDITS.md`. Herwig, Sherpa, WHIZARD и CalcHEP идут через образ контейнера, которому нужен Docker Desktop:

```
docker pull ghcr.io/gpasa/treelevel-tools:0.4.0
```

Больше ничего делать не нужно: TreeLevel сам создаёт временный контейнер для каждого задания. Docker Desktop должен быть запущен, когда стартует TreeLevel; тогда появляются генераторы образа с пометкой «(Docker)».

**У ядра нет окна.** Его запускает TreeLevel, всякий раз, когда это нужно. Если дважды щёлкнуть `treelevel-tools.exe`, Windows SmartScreen предупредит о нераспознанном приложении — ядро не подписано, — а после предупреждения консоль покажет инструкцию по использованию и закроется. Это нормально и ни на что не влияет.

### Что меняется

- **Одно ядро для Windows, Mac и образа.** Карточки генераторов теперь пишутся только один раз, на C++ (`Backends/engine`), и одна и та же программа работает здесь, на Mac и в контейнере. Часть для Windows теперь лишь находит Docker, образ и модуль Pythia.
- **«Tout faire tourner dans l'image Docker»** — флажок в «Настройках» TreeLevel 1.3. Когда он установлен, образ выполняет все задания, включая Pythia, и ничего не предлагается, если нет Docker или образа. Когда он снят, Pythia работает нативно, а остальное идёт через образ.
- **Что регистрирует эксперимент**: источник «Ускоритель» в TreeLevel 1.3 выбирает явление — всё, что видит детектор, рассеяние на фотоне, аннигиляцию в γ*/Z, обмен или рождение W, пары бозонов, струи, фоторождение, мягкие столкновения, — и ядро открывает его с подходящим порогом (Q² для рассеяний, p_T для струй).
- **Где родилась каждая частица**: управляющая программа Pythia записывает положения вершин и жёсткий процесс каждого события; TreeLevel рисует их и фильтрует по ним.
- **Pythia 8.318** везде, с её тюнами (`Monash 2013`, `A14`…), переведёнными в номера Pythia.
- **Пути с диакритикой**: папка задания под именем пользователя с диакритическими знаками открывается как любая другая.
- Удалено: путь через WSL (Herwig или Sherpa, установленные вручную в дистрибутив) — предусмотренный путь — Docker.
