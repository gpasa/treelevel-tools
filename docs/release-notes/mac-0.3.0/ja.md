TreeLevel が含むことのできない GPL ツールを、あなたのマシンで——そこから外に出るものは何もありません。TreeLevel はサンドボックス化されていてプログラムを一切起動しません。このパッケージが、それらの実行を許されている側です。

- `TreeLevel Tools.app` を `/Applications` にドラッグし、一度起動します。
- 四つの生成器が**すでに入っており**、ほかに何もインストールする必要はありません：
  - **Pythia 8** と **Herwig 7** は TreeLevel のイベントに肉付けします：シャワー、ハドロン化、崩壊。
  - **Sherpa 3** と **CalcHEP 3** には Les Houches リーダーがありません：プロトコルがイベントと並べて渡す過程の記述（ビーム、エネルギー、終状態、結合の次数）をもとに、ダイアグラムが表す過程を自ら計算します。
- すると TreeLevel は「生成」ワークスペースでそれらを提示します。

**WHIZARD 3** は含まれていません：各過程を gfortran でコンパイルしますが、gfortran は macOS にも Xcode にも付属しません。入手方法は二つあり、どちらも TreeLevel Tools のウィンドウでチェックします：

- **Docker イメージ** `ghcr.io/gpasa/treelevel-tools:0.3.0`。五つのツールを一貫した環境で備えています；
- あなた**自身のインストール**（MacPorts、Homebrew）、お持ちであれば。

どちらも既定では使われません：初期状態ではここに同梱の生成器だけが提示されるので、同じ書類は二台のマシンで同じ結果になります。

### 測定：200 GeV での e⁻e⁺ → W⁺W⁻

| エンジン | σ |
|---|---|
| TreeLevel | 19.22 pb |
| WHIZARD 3.1.6 | 19.441 ± 0.006 pb |
| CalcHEP 3.9.2 | 20.42 pb |
| Sherpa 3.0.5 | 18.2 ± 1.1 pb |

差は結合定数のスキームの選び方によるもので、誤りではありません。

### その他

- ジョブには番号と日時が付き、一覧に保存されます。
- モジュールのライブラリパスを実行時に修正：よそでコンパイルされたモジュールも、バイナリに手を加えずに動きます。
- 断面積は各生成器が置く場所から読み取ります：Asciiv3 の `C` 行、`GenCrossSection` 属性、または積分表。

README には、macOS 26 でモジュールをコンパイルする手順と、2026 年のツールチェーンが 2023 年のコードに仕掛ける四つか五つの罠が載っています。

Apple による署名と公証済み。チェックサムは `SHA256SUMS.txt` にあります。
