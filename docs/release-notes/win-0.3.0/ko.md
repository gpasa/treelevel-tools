> **[0.3.1](https://github.com/gpasa/treelevel-tools/releases/tag/win-0.3.1)로 대체되었습니다.** 이 버전은 `:0.3.0` 태그로만 이미지를 인식합니다. 0.3.1은 번호 없는 `docker pull`이 받는 `:latest`도 받아들입니다.

Windows에서 TreeLevel을 위해 몬테카를로 생성기를 돌리는 엔진입니다. 압축 파일을 `%LOCALAPPDATA%\Programs`에 풀기만 하면 설치됩니다—설치 프로그램도 없고 레지스트리에 남는 것도 없습니다.

여러분의 컴퓨터에 맞는 압축 파일을 고르십시오: Copilot+ PC나 ARM 태블릿이면 `arm64`, 그 밖에는 모두 `x64`. 헷갈릴 때는 x64판도 ARM에서 에뮬레이션으로 돌아갑니다.

**압축 파일의 내용**: 엔진과, 이 아키텍처용으로 컴파일된 Pythia 8 모듈. Herwig, Sherpa, WHIZARD, CalcHEP은 컨테이너 이미지 `ghcr.io/gpasa/treelevel-tools`를 거치며, 이 이미지에는 Docker가 필요합니다. **번호를 붙여** 받으십시오:

```
docker pull ghcr.io/gpasa/treelevel-tools:0.3.0
```

이 버전의 엔진은 이 태그만 인식합니다: 번호 없이 받은 이미지(즉 `:latest`)는 컴퓨터에 분명히 있지만, TreeLevel은 그 생성기를 제공하지 않습니다. 두 태그는 같은 이미지를 가리킵니다. 이미 `latest`가 있다면 위 명령은 태그만 덧붙입니다. TreeLevel이 시작할 때 Docker Desktop이 실행 중이어야 합니다.

### 생성기 다섯, 두 계열

**Pythia 8**과 **Herwig 7**은 TreeLevel이 넘겨주는 파톤 사건을 완성합니다: 샤워, 강입자화, 붕괴.

**Sherpa 3**, **WHIZARD 3**, **CalcHEP 3**에는 Les Houches 판독기가 없습니다—다이어그램이 기술하는 과정을 직접 계산합니다. 그래서 프로토콜은 사건과 나란히 과정의 기술(빔, 에너지, 최종 상태, 결합 차수)을 이들에게 전달합니다.

### 측정: 200 GeV에서 e⁻e⁺ → W⁺W⁻

| 엔진 | σ |
|---|---|
| TreeLevel | 19.22 pb |
| WHIZARD 3.1.6 | 19.441 ± 0.006 pb |
| CalcHEP 3.9.2 | 20.42 pb |
| Sherpa 3.0.5 | 18.2 ± 1.1 pb |

차이는 결합 스킴의 선택에서 오는 것이지, 오류가 아닙니다.

### 이번 버전의 새로운 점

- **충돌기 모드.** 생성기는 빔과 에너지만 받을 뿐 최종 상태는 결코 받지 않습니다: 진짜 가속기처럼 혼합 전체를 만들어 내고, TreeLevel은 그다음 그려진 과정의 특징을 지닌 사건을 셉니다—단면적을 계산하는 대신 측정하는 것입니다. 채널 계열은 여섯 가지이며, 그중에는 경성 QCD, 광생성, 전체 단면적이 있습니다. 지금은 Pythia 8만 해당합니다.
- **두 가지 가속기 구성의 조합.** 렙톤 빔은 렙톤으로, 또는 그것이 복사하는 광자 선속으로 들어가며, 한 번의 추출에서 둘 다가 되는 일은 없습니다: 엔진은 둘 다 추출하고, 각각의 단면적에 해당하는 몫을 각각에서 남깁니다.
- **보고되는 단면적은 마지막 사건 이후의 값입니다.** Pythia는 루프가 끝난 뒤에 정규화합니다. 드라이버는 진행 중인 추정값을 쓰고 있었고, 이는 수백 개 사건에서 12% 어긋났습니다.
- **프로그램 이름은 TreeLevel Tools**, 실행 파일은 `treelevel-tools.exe`입니다. 이제 몬테카를로 엔진만 담고 있는 것이 아닙니다.

### 그 밖에

- 작업에는 번호와 시각이 매겨지고 목록에 보관되며, TreeLevel이 다시 엽니다.
- 단면적은 각 생성기가 두는 곳에서 읽습니다: Asciiv3의 `C` 줄, `GenCrossSection` 속성, 또는 적분 표.

### 알려진 문제

Sherpa가 이미지가 아니라 개인 WSL 설치에서 실행되면, 렙톤 빔에서의 단면적이 너무 높게 나옵니다: 거기서는 QED 초기 상태 복사가 켜진 채로 남아, 200 GeV에서 e⁻e⁺ → b b̄가 3.2 대신 열다섯 피코반가량을 냅니다. `ghcr.io/gpasa/treelevel-tools` 이미지를 거치면 바로잡혀 있습니다.
