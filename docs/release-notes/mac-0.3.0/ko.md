TreeLevel이 담을 수 없는 GPL 도구를 여러분의 컴퓨터에서—아무것도 밖으로 나가지 않습니다. TreeLevel은 샌드박스 안에서 실행되며 어떤 프로그램도 실행하지 않습니다. 이 패키지가 그 도구들을 실행할 수 있도록 허용된 쪽입니다.

- `TreeLevel Tools.app`을 `/Applications`로 끌어다 놓고 한 번 실행합니다.
- 생성기 네 개가 **이미 들어 있으므로** 따로 설치할 것이 없습니다:
  - **Pythia 8**과 **Herwig 7**은 TreeLevel의 사건을 완성합니다: 샤워, 강입자화, 붕괴.
  - **Sherpa 3**과 **CalcHEP 3**에는 Les Houches 판독기가 없습니다: 프로토콜이 사건과 나란히 전달하는 과정의 기술(빔, 에너지, 최종 상태, 결합 차수)에 따라, 다이어그램이 기술하는 과정을 직접 계산합니다.
- 그러면 TreeLevel이 ‘생성’ 작업 공간에서 이들을 제공합니다.

**WHIZARD 3**은 포함되어 있지 않습니다: 각 과정을 gfortran으로 컴파일하는데, macOS도 Xcode도 gfortran을 제공하지 않습니다. 이를 갖추는 방법은 두 가지이며, 둘 다 TreeLevel Tools 창에서 체크합니다:

- **Docker 이미지** `ghcr.io/gpasa/treelevel-tools:0.3.0`, 다섯 가지 도구를 일관된 환경에 담고 있습니다;
- 여러분 **자신의 설치**(MacPorts, Homebrew), 있다면.

기본적으로는 둘 다 쓰이지 않습니다: 처음 상태에서는 여기에 번들된 생성기만 제공되므로, 같은 문서는 두 컴퓨터에서 같은 결과를 냅니다.

### 측정: 200 GeV에서 e⁻e⁺ → W⁺W⁻

| 엔진 | σ |
|---|---|
| TreeLevel | 19.22 pb |
| WHIZARD 3.1.6 | 19.441 ± 0.006 pb |
| CalcHEP 3.9.2 | 20.42 pb |
| Sherpa 3.0.5 | 18.2 ± 1.1 pb |

차이는 결합 스킴의 선택에서 오는 것이지, 오류가 아닙니다.

### 그 밖에

- 작업에는 번호와 시각이 매겨지고 목록에 보관됩니다.
- 모듈의 라이브러리 경로를 실행 시에 바로잡습니다: 다른 곳에서 컴파일된 모듈도 바이너리에 손대지 않고 작동합니다.
- 단면적은 각 생성기가 두는 곳에서 읽습니다: Asciiv3의 `C` 줄, `GenCrossSection` 속성, 또는 적분 표.

README에는 macOS 26에서 모듈을 컴파일하는 방법과, 2026년의 툴체인이 2023년의 코드에 놓아 둔 네다섯 가지 함정이 실려 있습니다.

Apple이 서명하고 공증했습니다. 체크섬은 `SHA256SUMS.txt`에 있습니다.
