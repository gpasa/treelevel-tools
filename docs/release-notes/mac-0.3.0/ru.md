Инструменты под лицензией GPL, которые TreeLevel не может содержать, на вашем компьютере — ничто его не покидает.
TreeLevel работает в песочнице и не запускает никаких программ; этот пакет — то, чему разрешено их выполнять.

- Перетащите `TreeLevel Tools.app` в `/Applications` и запустите один раз.
- Четыре генератора **уже внутри**, больше ничего устанавливать не нужно:
  - **Pythia 8** и **Herwig 7** достраивают события TreeLevel: ливень, адронизация, распады.
  - У **Sherpa 3** и **CalcHEP 3** нет считывателя Les Houches: они сами вычисляют процесс, описанный
    диаграммой, по описанию процесса (пучки, энергии, конечное состояние, порядки по константам связи),
    которое протокол передаёт им наряду с событиями.
- После этого TreeLevel предлагает их в разделе «Генерация».

**WHIZARD 3** не включён: он компилирует каждый процесс с помощью gfortran, которого нет ни в macOS, ни в Xcode.
Два способа его получить, оба включаются флажком в окне TreeLevel Tools:

- **образ Docker** `ghcr.io/gpasa/treelevel-tools:0.3.0`, содержащий все пять инструментов в согласованном окружении;
- ваша **собственная установка** (MacPorts, Homebrew), если она у вас есть.

Ни один из них не используется по умолчанию: изначально предлагаются только генераторы, входящие в этот пакет, чтобы один и тот же документ давал один и тот же результат на двух компьютерах.

### Измерено: e⁻e⁺ → W⁺W⁻ при 200 GeV

| программа | σ |
|---|---|
| TreeLevel | 19,22 pb |
| WHIZARD 3.1.6 | 19,441 ± 0,006 pb |
| CalcHEP 3.9.2 | 20,42 pb |
| Sherpa 3.0.5 | 18,2 ± 1,1 pb |

Расхождения объясняются выбором схемы констант связи, а не ошибками.

### Также

- Задания пронумерованы, снабжены отметкой времени и хранятся в списке.
- Пути к библиотекам модуля исправляются во время выполнения: модуль, скомпилированный в другом месте, работает без правки его двоичных файлов.
- Сечение считывается там, куда его помещает каждый генератор: строка `C` в Asciiv3, атрибут `GenCrossSection` или таблица интегрирования.
