Windows 上の TreeLevel のためにモンテカルロ生成器を動かすエンジンです。書庫を `%LOCALAPPDATA%\Programs` に展開するだけでインストールできます——インストーラもなく、レジストリにも何も残しません。以前のバージョンを**更新するには**、TreeLevel を閉じ、書庫を同じ場所に展開してファイルを置き換えます。

お使いのマシンに合う書庫を選んでください：Copilot+ PC や ARM タブレットなら `arm64`、それ以外はすべて `x64`。迷ったら、x64 版も ARM でエミュレーションで動きます。

**書庫の内容**：エンジンと、このアーキテクチャ向けにコンパイルされた Pythia 8 モジュール。Herwig、Sherpa、WHIZARD、CalcHEP はコンテナイメージを通ります。それには Docker Desktop が必要です：

```
docker pull ghcr.io/gpasa/treelevel-tools
```

ほかに必要なことはありません：TreeLevel がジョブごとに使い捨てのコンテナを自ら作ります。TreeLevel の起動時に Docker Desktop が動いている必要があります。そうすれば、イメージの生成器が「(Docker)」の印付きで現れます。

**エンジンにはウィンドウがありません**。必要になるたびに TreeLevel が起動します。`treelevel-tools.exe` をダブルクリックすると、Windows SmartScreen が認識されないアプリだと警告します——エンジンは署名されていません——。警告を越えると、コンソールが使い方を表示して閉じます。これは正常で、何の影響もありません：自分で起動する必要は一切ありません。

### このバージョンの修正

- **番号なしで pull したイメージが認識されます**。0.3.0 はタグ `:0.3.0` しか認識しませんでした。ところが、パッケージのページが示すコマンド、そして誰もが打つコマンドは `:latest` を pull します。イメージはマシンにあり、手で起動すれば応答したのに、TreeLevel は Pythia しか提示しませんでした。二つのタグは同じイメージを指しており、今はどちらも認識されます。
- **レプトンビームでの Sherpa**（イメージの外で動かす場合）：その断面積が QED の始状態放射で膨らまなくなりました（200 GeV での e⁻e⁺ → b b̄ で、3.2 ではなく十五ピコバーンほど）。これに頼っていた経路——WSL に自分でインストールした Sherpa——は今後のバージョンで削除されます：Docker が想定された経路です。

### 五つの生成器、二つの系統

**Pythia 8** と **Herwig 7** は、TreeLevel が渡すパートンのイベントに肉付けします：シャワー、ハドロン化、崩壊。

**Sherpa 3**、**WHIZARD 3**、**CalcHEP 3** には Les Houches リーダーがありません——ダイアグラムが表す過程を自ら計算します。そこでプロトコルは、イベントと並べて過程の記述（ビーム、エネルギー、終状態、結合の次数）を渡します。

### 測定：200 GeV での e⁻e⁺ → W⁺W⁻

| エンジン | σ |
|---|---|
| TreeLevel | 19.22 pb |
| WHIZARD 3.1.6 | 19.441 ± 0.006 pb |
| CalcHEP 3.9.2 | 20.42 pb |
| Sherpa 3.0.5 | 18.2 ± 1.1 pb |

差は結合定数のスキームの選び方によるもので、誤りではありません。

### おさらい：0.3.0 がもたらしたもの

- **コライダーモード**。生成器が受け取るのはビームとエネルギーだけで、終状態は決して受け取りません：本物の加速器のように混合全体を生み出し、TreeLevel はそのあと、描かれた過程の特徴を持つイベントを数えます——断面積を計算する代わりに測定するのです。六つのチャンネル群があり、ハード QCD、光生成、全断面積を含みます。今のところ Pythia 8 のみです。
- **二つの加速器構成の組み合わせ**。レプトンビームはレプトンとして、あるいはそれが放射する光子のフラックスとして入り、同じ試行で両方になることはありません：エンジンは両方を生成し、それぞれの断面積に見合った割合を各々から残します。
- **報告される断面積は最後のイベントの後の値です**。Pythia はループの後で規格化します。ドライバは途中の推定値を書いており、数百イベントでは 12% ずれていました。
- **プログラムの名前は TreeLevel Tools**、実行ファイルは `treelevel-tools.exe` です。
- ジョブには番号と日時が付き、一覧に保存され、TreeLevel が開き直せます。断面積は各生成器が置く場所から読み取ります。
