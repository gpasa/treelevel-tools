# Une machine : e⁻e⁺ à 200 GeV, « tout ce que le détecteur voit »

Pythia 8 mène la machine ; le pilote étend « inclusive » en annihilation, paires de bosons, diffusion au-delà
de dix degrés, W échangé, et le flux de photons à part — deux tirages que l'engin réunit. Mesuré sur le Mac
et dans l'image : 1 125 pb, presque tout de la diffusion Bhabha au-delà de dix degrés.
